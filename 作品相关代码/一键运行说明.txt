lit-agent 一键运行说明


一、怎么用

双击本目录下的“一键运行.bat”，然后等它自己跑完就行。它现在同时负责启动
OpenCLI Browser Bridge 和本地网页，不需要再单独打开另一个启动脚本。跑完之后
浏览器会自动打开网页，地址是 http://127.0.0.1:8501；要是没自动弹出来，手动把
这个地址输进浏览器。要停止服务，直接关掉那个命令行窗口。

代码放在同目录的 scr 子文件夹里，脚本会自己找到它，不用改路径。以后要是把代码
挪到别的文件夹，只要 bat 还在它旁边或者它上一层就行。

顺便说一下脚本里的提示为什么是英文的：cmd 在中文环境下读非英文字符会把行读串，
批处理会报“不是内部或外部命令”这类看不懂的错，试了几次只能把提示写成英文。
中文说明都放在这个文件里，两者是配套的。

如果只想检查环境、不启动网页，把 bat 拖进命令行，后面加一个 check：

    一键运行.bat check


二、脚本做了哪几件事

1. 找 Python。版本低于 3.12 会提示。
2. 检查 requests、jieba、PyMuPDF、streamlit、numpy、onnxruntime、sentencepiece，
   缺了就自动装。第一次装要联网，具体时间取决于网络。
3. 建好 data 目录和 SQLite 的表结构，重复执行也没问题。
4. 建索引，包括 BM25 倒排、n-gram 精确指纹和神经向量。这一步是增量的，
   已经建好的文献会跳过，所以第二次运行通常只要几秒。
5. 启动带 Browser Bridge 的 OpenCLI 专用浏览器，并检查桥接是否已连接。
6. 启动网页并打开浏览器。网页包含 Agent 对话、溯源、文献库和查询历史四个页签。

运行日志写在 data\logs\litagent.log，会自动轮转。一次溯源最多处理 20,000 字，
超过时会提示截取最关键的一段，避免超长输入拖慢整个系统。

进入“文献库”后展开“从本地导入文献（自动清洗并建索引）”，可以直接上传
PDF、DOCX、DOC、RTF、TXT、Markdown 或 HTML 文件，也可以用“选择文件夹”
批量导入本机目录。导入完成后系统会自动清洗和建立全部索引，不需要再执行
命令行。旧版 DOC/RTF 需要本机安装 Microsoft Word、WPS 或 LibreOffice。


三、环境要求

Windows 10 或 11，Python 3.12 以上。
不需要显卡，也不用另外装数据库。

依赖清单全部锁定到精确版本，在干净电脑上重复安装会得到同一套版本。

神经向量模型位于 data/models，需要由 Git LFS 完整下载。如果从 GitHub 克隆后
看到的是几十字节的 LFS 指针，请在代码目录执行 git lfs pull。


四、需要填密钥吗

不填也能演示。检索、清洗、建索引、引文溯源这四项都不需要密钥，也不联网。

只有“对话”和“总结”要用大模型。把 .env.example 复制一份改名成 .env，填一行：

    LIT_LLM_API_KEY=你的密钥

密钥在 https://platform.deepseek.com/ 申请。因为密钥不方便公开，交付版本里的
.env 可能没有有效密钥，这是正常的，不影响上面四项功能的演示。


五、出问题怎么办

浏览器没弹出来：手动打开 http://127.0.0.1:8501

首次启动提示 OpenCLI Browser Bridge 未连接：这是 Edge 158 以后的安全限制。
脚本会自动打开扩展管理页和扩展文件夹。启用“开发者模式”，点“加载解压缩的
扩展”，选择脚本打开的那个文件夹。确认一次后重新运行“一键运行.bat”即可。

提示端口被占用：换个端口启动，然后访问对应的地址。

    python cli.py ui --port 8502

页面里没有文献：data 目录被清空了，抓一些回来。

    python cli.py fetch -q "图神经网络 推荐系统" --limit 20

溯源提示没找到：这是正常的，只有已经收进库里的文献才能被溯源到。可以在界面上勾
“本地找不到时联网”，返回的只是候选线索，需要自己核实原文。

想彻底重来：关掉服务，删除 index.db、cache、clean、pdfs、raw 和 summaries，
保留 data/models 与需要复现的 data/evaluation，再双击“一键运行.bat”会重建空库。
