## 本轮修复

- `fresh_reg.py` 改用 `production_baseline_v3.json`，消除历史 v1 基线造成的
  逻辑哈希失败。
- 微改动测试会先确认文本确实发生变化，避免替换条件未命中时形成假失败。
- 无关文本的合法结果更新为 `none` 或 `local_semantic`，共同要求
  `found=false` 且置信度为 0。
- 总结完整度按 `summary_quality` 的内容级别规则判断；题录级和摘要级文献不再
  因缺少全文才能生成的字段被判为失败。
- 数据质量中的摘要完整率只在全文/摘要级文献中统计。
- `normalize_doi` 现在会去掉 DOI 末尾斜杠。
- JSON 测试改用合法转义样例，同时明确验证非法 JSON 返回 `None`。
- 黑盒联网候选检查改为读取真正的 `online_candidates` 字段。

## 网页多格式导入回归

支持 PDF、DOCX、DOC、RTF、TXT、Markdown 和 HTML/HTM。网页支持一个或多个
文件上传，以及 Windows 文件夹选择；导入后自动完成入库、清洗、分块、BM25、
精确指纹和本地语义向量索引。

已验证：

- TXT 与 DOCX 文件夹批量导入；
- 浏览器上传文本文件；
- DOC/DOCX/HTML 正文解析；
- 重复导入不会新增重复文献；
- 导入后自动创建索引；
- Streamlit 页面无异常，上传、选择文件夹和开始导入控件正常显示。
